# Enhanced Deep Learning Techniques for Automatic Brain Tumor Identification and Categorization Using MRI Images
This project classifies brain tumors from MRI images using deep learning models such as CNN, VGG16, and ResNet50.

## Dataset
Download dataset from [Cick here](https://your-link.com](https://drive.google.com/drive/folders/16zxQtxWIdQTkzEuHDwIoDsHT2NgRT3yI?usp=drive_link)) 
- MRI brain scans categorized into:
  - **Glioma**
  - **Meningioma**
  - **Pituitary**
  - **No Tumor**

## How to Run
1. Load dataset (via Google Drive)
2. Run the BrainTumorDetection.ipynb in google colab
3. View results, plots, and saved models

## Libraries Used

This project uses the following major Python libraries:

- **TensorFlow** - Deep learning model building and training  
- **NumPy** - Numerical computations  
- **Matplotlib** - Plotting graphs and visualizations  
- **Seaborn** - Statistical data visualization  
- **Pandas** - Data manipulation and analysis  
- **scikit-learn** - Classification metrics and model evaluation  
- **PIL (Pillow)** - Image loading and preprocessing
  
 ## Recommended Library Versions

The following versions were used and tested in this project:

- Python 3.8+
